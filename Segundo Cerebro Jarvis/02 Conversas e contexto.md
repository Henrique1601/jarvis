# 💬 Conversas e contexto

## Separar assuntos

Crie uma conversa para Estudos JavaScript, outra para Trabalho e outra para Ideias. Renomeie com um título reconhecível. A busca ajuda a localizar conversas; trocar de conversa deve mostrar apenas suas mensagens e pedidos. O histórico anterior é preservado numa conversa geral pela migração.

## Escolher o que enviar à IA

Antes de enviar, selecione até seis notas de referência e decida se quer incluir tarefas. Uma seleção explicitamente vazia significa conversar sem notas. As respostas anteriores da própria conversa podem participar do contexto. Outras conversas não devem entrar automaticamente.

O contexto completo continua limitado a 32 mil caracteres, com pedido de até 12 mil. Uma nota selecionada pode ter somente trechos incluídos para respeitar esse limite. As fontes da resposta permitem conferir quais referências participaram.

## Usar respostas

Copie uma resposta inteira ou um bloco de código. Guardar resposta abre uma nota com o Markdown original, mesmo quando o painel mostra conteúdo formatado. Código copiado continua exigindo revisão antes de executar.

Pedidos aguardam até sete dias quando o Windows estiver indisponível. Você pode cancelar. Resultado incerto exige decisão de reenvio; não há nova geração automática.
